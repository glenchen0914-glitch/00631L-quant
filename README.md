# 00631L Quant V5.0

V5.0 把原本的固定規則回測，升級為「策略群組＋市場環境＋機器學習輔助」的每日決策系統。

## V5.0 核心升級

- Top 5 策略投票，不再只看單一最佳策略
- 台股、NASDAQ、SOX、S&P 500、VIX、美元、美債、台積電 ADR 市場環境評分
- Random Forest 時序交叉驗證
- 預測未來 5 日上漲超過 2% 的機率
- 落底進度拆成周KD、RSI、日KD、MACD、均線、波動、融資、市場環境
- 第一筆、第二筆、第三筆與停止加碼價位
- 回測可信度、樣本外交易筆數與過度擬合警告
- GitHub Actions 自動執行
- Google Colab 手機版一鍵執行

## 重要說明

V5.0 的機器學習模型只作為輔助訊號，不會單獨決定買賣。系統會同時考慮：

1. 落底進度
2. 市場環境
3. Top 5 策略投票
4. 機器學習機率
5. 樣本外回測可信度
